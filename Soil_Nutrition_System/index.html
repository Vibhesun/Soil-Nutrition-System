ABOUT THE PROJECT

Healthy soil is the starting point.

Soil Nutrition System is an educational project concept that explains how sensors, a microcontroller, and a web interface can work together to observe soil conditions.

◎

The problem

Soil conditions can vary across a field. Guessing moisture or nutrient needs may lead to overwatering, unnecessary fertilizer use, or poor crop growth.

⌁

The proposed solution

Collect soil readings, send them through an IoT device, display the values on a dashboard, and provide clear guidance based on configured thresholds.

↗

Project objectives

  • Make soil data easier to understand
  • Support timely irrigation decisions
  • Encourage evidence-based soil care
Important: This front-end demo does not connect to physical sensors. Nutrient values and recommendations are sample content for explaining the system. Actual N, P, and K measurements require compatible sensors or laboratory testing.

SYSTEM WORKING PROCESS

From soil to screen.

The typical workflow below explains how the physical system and web application can exchange data.

01⌁

Sense

Soil sensors collect supported readings such as moisture and temperature. pH and NPK require suitable sensing hardware or external test data.

INPUT: SENSOR SIGNALS
→
02▤

Process

A microcontroller such as ESP32 reads the sensor signals, applies calibration, and prepares a timestamped data record.

DEVICE: ESP32 / MCU
→
03⌁

Transmit

The device sends data over Wi-Fi or another connection to a backend API or IoT platform using a defined data format.

NETWORK: WI-FI / API
→
04▥

Visualize

The web app retrieves readings, shows trends, checks thresholds, and presents understandable status messages to the user.

OUTPUT: DASHBOARD
